# GEO Experiment V1

## Objective

Measure how visible a brand is across generative AI search experiences
for commercially relevant prompts.

## Test Brand

ChargeOps AI

## Competitor Set

Competitors will be discovered from:
- Google search results
- AI-generated answers
- Industry research

## AI Engines

Initial targets:
- ChatGPT
- Gemini
- Claude
- Perplexity
- Google AI Overviews

## Prompt Categories

1. Informational
2. Commercial investigation
3. Comparison
4. Recommendation
5. Problem / solution
6. Brand-specific

## Example Prompts

### Informational
- What is EV charging management software?
- How does EV charging management work?

### Commercial
- Best EV charging management platforms
- Best EV charging software for businesses

### Comparison
- Compare EV charging management platforms
- What are the alternatives to leading EV charging platforms?

### Recommendation
- Which EV charging platform should a commercial property use?
- Recommend software for managing multiple EV charging stations

### Problem / Solution
- How can businesses monitor multiple EV charging stations?
- How can an operator reduce EV charger downtime?

### Brand Specific
- What is ChargeOps AI?
- Is ChargeOps AI suitable for EV charging operators?

## Data To Capture

For every prompt:

- prompt text
- prompt category
- AI engine
- model
- execution date
- complete response
- brands mentioned
- brand mention order
- citations
- cited domains
- recommendation status
- response sentiment/context
- competitors mentioned

## Metrics

- Brand Mention Rate
- Citation Rate
- Recommendation Rate
- Average Mention Position
- Prompt Coverage
- AI Share of Voice
- Competitor Share of Voice

## Experimental Principle

Use the same or equivalent prompt set across engines.

Repeat measurements over time because AI-generated answers can change.

Do not assume a single AI response represents permanent ranking behavior.
